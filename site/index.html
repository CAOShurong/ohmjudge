Ten domains, not one disguised formula.

Every domain contains five independently named templates. The current release emphasizes auditable numerical reasoning and unit discipline.

V

Circuits

Dividers, filters, op-amps, Thevenin models, series networks.

∿

Signals

RMS, sampling, aliases, energy, convolution.

ζ

Control

Poles, overshoot, settling, stability, gain.

RF

Communications

Capacity, path loss, noise, symbols, link budgets.

Q

Electronics

Diodes, BJTs, MOSFETs, ADCs, slew rate.

3φ

Power

Three-phase loads, transformers, energy, PF, batteries.

λ

Electromagnetics

Waves, fields, capacitance, magnetic flux, inductance.

01

Digital

Timing, clock limits, counters, encodings, distance.

µC

Embedded

UART, PWM, timers, buffers, I2C transfers.

Δ

Instrumentation

Shunts, sensors, uncertainty, dB, bridge outputs.

Clear boundaries are part of the benchmark.

A score is meaningful only inside the construct actually tested.

Not professional certification.Scalar calculation performance does not establish safe hardware-design competence.
Not contamination-proof.Fresh parameters reduce exact memorization, but formulas and template families can remain familiar.
Not an official model ranking.Web products, API model IDs, routing, tools, and dates must be reported separately.
Not a replacement for simulation.SPICE, HDL, EDA, laboratory measurement, and safety validation remain future task classes.

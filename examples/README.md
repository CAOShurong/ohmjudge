# Examples

`pricing.example.json` documents the expected price-table shape. Replace every
placeholder before using it in a report; zero values in the example are not a
claim that any provider is free.

To produce safe demonstration artifacts, run:

```bash
ohmjudge demo --output demo
```

The command creates tasks, public prompts, synthetic responses, grades, a report,
and a no-API lab. The fake model names are deliberately non-commercial.
